# 银杏 (yinxing.monkey)

> 115 网盘 Tampermonkey 用户脚本 — 磁力链接助手 + 文件自动整理

## 功能

- **磁力链接助手** — 点击 `magnet:` / `ed2k:` 链接时自动复制到剪贴板并发送到 115 离线下载
- **文件自动整理** — 解析文件名中的番号，查询元数据，自动按厂商分类归档
- **UI 增强** — 自定义缩略图网格、注入操作菜单

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Greasemonkey](https://www.greasespot.net/)
2. 从 [Greasy Fork](https://greasyfork.org/) 安装脚本（待发布）
3. 或直接使用 jsDelivr CDN：`https://cdn.jsdelivr.net/npm/yinxing.monkey@latest/index.js`
